# _briefs

Content briefs for new pages in the Teacher Toolkit site.

## How to use

1. Copy `brief-template.md` and rename it to describe your page (e.g. `engineering-resistors.md`)
2. Fill in all sections
3. Add any reference images to `assets/`
4. Ask Claude Code to action the brief
5. When the page is merged, move the brief to `done/`

## Rules

- Briefs are for **content pages only** — not new tools
- Output path must be specified in every brief
- One brief per page
